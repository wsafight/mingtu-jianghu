# 命途江湖

用 Astro 构建的《活侠传》攻略书。纸色与夜读主题，提供十七章攻略、留档年表、可定位小节的全文搜索、首页收藏列表、自查清单与小师妹 roll 推算。

游戏条件以本机 **1.0.6000.4** 为基准，最近核对日期为 **2026-10-20**。六条感情线都按「提前准备 → 具体选择 → 成功标志 → 漏项排查」展开，包含日常好感、梦境换心上人、关键战斗、结缘与奖励的区别。小师妹、夏侯兰、龙湘、虞小梅和郁竹分别有 16–18 节详细走法，补齐雪山养成、大会收容、小梅六句唤醒、小竹最终战第 15 回合等操作。锻造与毒药章逐项列出开发前置、门派规模、成本、满级效果和丹药服用效果。

## 章节如何分工

| 要查什么 | 章节 |
| --- | --- |
| 第一次开档、分清概念 | 行前须知、江湖年表 |
| 跟着选项走剧情 | 六条人物路线，保留连续流程与现场战法 |
| 救大师兄、选主线 | 师门风雨、西武林盟 |
| 配装与防守、排行动和钱 | 战斗准备、行动与预算 |
| 比较开发需求和效果 | 锻造与毒药 |
| 找图纸、药方、逆鳞与路线奖励 | 图纸与特殊装备 |
| 查成就需求、额外行动、命运继承 | 成就与继承 |
| 卡住或核查出处 | 查漏补缺、版本与依据 |

人物篇开头只留本线预算入口；六份长预算表集中在资源章各自的小节。图纸的六线可得表与跨线条件集中在来源章。旧章节地址保留，移动过的预算、共用准备和图纸小节仍留原锚点及新入口。

## 本地阅读

需要 Node.js 22.12 以上。

```sh
npm ci
npm run dev -- --port 4321
```

打开 <http://127.0.0.1:4321/>，叶云裳详细章位于 <http://127.0.0.1:4321/guide/cloud/>，锻造与毒药章位于 <http://127.0.0.1:4321/guide/crafting/>。

```sh
npm run build
npm run preview -- --port 4321
```

`build` 先运行 Astro 类型与内容检查，再生成 `dist/` 静态网站。`preview` 用于阅读构建结果。

## 内容与下载

- `src/content/chapters/`：攻略正文，叶云裳为 `cloud.md`。
- `src/data/book.ts`：章节说明与自查清单。
- `src/data/downloads.json`：网页入口与同步脚本共用的单章下载文件名。
- `src/data/timeline.json`：年表数据；`timeline.md` 保留相同内容，供全文搜索。
- `public/downloads/` 中六个人物的 `完整路线攻略.md`：各线单章下载，包含叶云裳与本次扩写的五篇。
- `public/downloads/锻造与毒药需求效果图鉴.md`：40 项开发定义及丹药效果的单章下载。
- 新增专题下载：`战斗准备与关键决斗指南.md`、`六线行动与预算手册.md`、`图纸药方与特殊装备取得指南.md`。
- `public/downloads/成就与继承需求效果指南.md`：22 项风云史的需求、效果、特殊前置与收藏命运奖励算法。
- `public/downloads/活侠传关键节点选择攻略.md`：完整原文下载。
- `public/reference/`：用于核对的条件资料。

新增了三场关键战斗的防守构筑与分阶段操作、大师兄两类自然幸存条件、逆鳞整段取得链和六线行动／预算示例。年表共 34 个节点，核对索引共 28 条结论。战法与排期依据脚本和机制整理，尚未用普通养成档完整实测。

修改正文后运行 `npm run sync`。该命令以章节为准生成上一级完整原文、完整下载与十一个单章下载（六条路线、战斗、预算、锻造、图纸取得、成就继承），共 12 份下载；将网站链接转成离线 Markdown 可用的章节／小节锚点与资料路径；`scripts/heading-map.mjs` 使用与 Astro 相同的 Markdown 渲染器，整书小节按章节加命名空间以避免重复。更新年表只改 `src/data/timeline.json`，同步时会自动生成年表章。`npm run build` 会先自动同步，再检查和构建。整书顺序跟随 `src/data/book.ts`，不再维护另一套手工合并原文。

`scripts/extract-crafting.py` 只读本机游戏资源，使用上一级 `mortal-tools/.venv` 内的依赖，生成 `public/reference/crafting.json`；`python3 scripts/build-crafting-chapter.py` 从该数据生成锻造表格与图纸取得章，然后调用统一同步脚本，更新章节与下载版。锻造和图纸取得两章的文字修改应在此生成脚本中维护，避免再次生成时覆盖。

成就正文维护在 `src/content/chapters/achievements.md`。运行 `../mortal-tools/.venv/bin/python scripts/extract-achievements.py` 可只读重新提取本机成就与收藏定义、奖励档位和剧情发放位置，写入 `public/reference/achievements.json`，不会操作游戏存档或 Steam。当前为 22 项风云史、122 种死法、66 项汗青、6 项 CG，84 处成就发放调用。额外行动的新周目结算、六项人物成就的西盟尾声要求和 322 点收藏奖励上限均单独说明；不把定义或脚本核对说成全成就实机解锁。

搜索使用 `⌘ K` / `Ctrl K`，输入关键词后可直接跳到相关小节，折叠正文会自动展开。首页「我的收藏」可打开或移除已收藏的卷。窄屏章节顶部有可展开的阶段目录；浏览器打印可输出干净正文。收藏、勾选、阅读位置与主题保存在当前浏览器的 `localStorage` 中；清除浏览器数据会清除这些记录。

本项目只提供攻略，不读取或改写游戏存档。

整书审阅记录见 `docs/攻略书审阅记录.md`，列出已修正的问题、按顺序补全的五项和实际验证边界。年表支持跨年事件；打印本章会包含折叠的剧透正文，打印后恢复原来的展开状态。单章下载跨章查阅时需与完整版放在一起，核对资料需保留相应目录，交互式 roll 工具需要本地网站运行。

`public/reference/route-audit.json` 记录本次重点核对结论与脚本／条件名；正文的适用范围、未穷尽入口和官方版本记录见「版本与依据」。本次为脚本与数据核对，并非每条路线所有变体的实机通关报告。
