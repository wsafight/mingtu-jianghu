## 1. 先取得提案，再亲自决定成立

第三年十二月上旬的 **集思广益 → 来访 → 最终决策** 是连续分流。先在这里留档，优先准备 **李富贵来访或主角自提** 中一种可用的途径，最后亲自选 **「决策：我们也来成立武林盟」**。

魏菊的提案对白确实存在，战术 8／战术 5＋学问 50 只改变其中对白；但还必须在 **本次集思广益时，她已在唐门**。本书尚未确认当前版本常规六线中、成立决策前让她到场的稳定走法，**因此不把她列为新手可直接依靠的保底入口**。

## 2. 两种优先准备的入口与一项条件分支

| 途径 | 真正要满足的条件 | 怎么确认取得了提案 |
| --- | --- | --- |
| 李富贵来访 | **李富贵好感至少 30，而且丐帮好感至少 3** | 他来唐门讲述遗策，明确建议成立西武林盟 |
| 魏菊的有条件分支 | **本次集思广益之前，魏菊已经在唐门**；选她的话题时 **心相大于 20**；本场尚未请教 | 先确认菜单确有「访问小菊」，再谈上中下三策；只在实际有此入口时使用 |
| 主角自提 | **金乌上人已死**，并且 **战术至少 8**；或 **金乌已死、战术至少 5、学问至少 60** | 最终决策前的自提检查通过，成立选项可用 |

具备一种实际可用的资格即可，不需全部达成。李富贵的 **本人好感** 和 **丐帮好感** 是两组数值，只有本人 30 仍可能没有来访提案。

### 李富贵本人好感怎样准备

前期后山劳动遇见他借陷阱打猎、分猪脚的结果，会加他好感 **2**。下山遇见他想喝饮子时，选 **「请客」**，花 200 钱，对应两种回应都会加他好感 **2**；选「买来喝给他看」反而扣他好感 1、丐帮好感 1。

如果遇到他踩中云裳陷阱的另一段，**告状替他讨回公道** 会加他 2，但云裳减 1；包庇云裳则李富贵减 2。走云裳线兼顾这项提案时，优先利用双方都加分的打猎结果，避免临近决策才发现李富贵被扣到 30 以下。

### 丐帮 3 与本人 30 要分开积累

打猎或请客加的是本人，不会同时给丐帮同样的数值。炼丹房工作时，若遇到丐帮弟子求诊、承诺以后不为难唐门的事件，选 **「一言为定」** 治好他，对应 **丐帮好感 +1、贡献 −10、向心力 −1**；这是有师门代价的让步，另存后再决定。

此类工作结果不是每次必出，也不是固定做三次炼丹就一定达到 3。前期遇到时逐次积累，十二月前检查丐帮当前关系；若仍不够，应提早准备主角自提，不能只看李富贵好感已满。其他主线事件也会加减丐帮关系，本章未把它们当作所有路线统一必做项。

## 3. 魏菊：先确认决策前在场，再谈心相

目前核到的大会返程安顿她的脚本，还要求已有她的感情攻略记录；另一个普通的崆峒援军来访，位于 **成立西盟后的外交阶段**。后者即使让她到唐门，也已经晚于本次集思广益，**不能倒补成立资格**。

这说明「请教后会给提案」与「当前周目能在决策前请教她」是两件事。她在未来援军事件会出现、以前认识她，或已去过玄功门，都不足以证明本场可选。

集思广益可以向多位人物请教。 **每问一人消耗 7 心相，开启下一人的话题要求当前心相大于 20。** 正好 20 不可选。

若你依靠魏菊提案，进入前恢复心相，并优先问她。不要先把所有人都问完，结果她的话题因为心相不足消失。她不在唐门时，堆战术和学问不能代替人物在场。

| 容易混淆的条件 | 实际作用 |
| --- | --- |
| 战术 8，或战术 5＋学问 50 | 改变魏菊讨论时你是否已经想到策略的对白； **不阻止这段谈话发放提案** |
| 魏菊在唐门、心相 >20、尚未请教 | 决定本场能否选择她的话题 |
| 谈完魏菊的策略 | 实际建立可以成立西武林盟的资格 |

只达到数值、没有选择她的话题，不会自动获得她的建议；仅仅听完其他人也不能代替。

## 4. 李富贵与福韫：不要混成同一种来访

李富贵满足本人 30、丐帮 3 的条件时，会进入带有西武林盟遗策的来访。福韫尚在且好感至少 30，会影响是否与他一起来。

**只有福韫单独来帮忙，不等于已经拿到李富贵的遗策。** 当前脚本把福韫单独来访与李富贵提案分开处理；前者不会设置同一个成立资格。若只见到福韫，优先检查主角自提；魏菊只在本场已经能访问她时考虑。

## 5. 主角自提：比魏菊对话多一层要求

最终决策前，主角可以在满足下列任一组条件时自己提出：

- **金乌上人已死＋战术 ≥8**。
- **金乌上人已死＋战术 ≥5＋学问 ≥60**。

“击败过金乌”与“金乌已死”是两种记录，不要把比武首战获胜直接算作死亡。也不要把魏菊对话中的学问 50，错套到主角自提的学问 60 上。

感情线没有走到金乌死亡结果时，应提前准备李富贵途径；不要到最后才把尚未确认到场的魏菊当作兜底。

## 6. 决策菜单怎么选

有了资格后，选：

> **「决策：我们也来成立武林盟」**

| 决策文字 | 对应方向 |
| --- | --- |
| 决策：我们也来成立武林盟 | 西武林盟 |
| 决策：战他娘亲 | 顽抗 |
| 决策：退隐江湖 | 退隐 |
| 决策：响应武林盟 | 响应既有武林盟的方向 |

当前菜单会按资格隐藏部分决策，因此别预设每周目都能看到整张表。若成立项没出现，回到 **集思广益前** 检查提案；已经选了其他决策，再提高学问不会自动改线。

**成功标志：** 你亲自选下成立，进入西武林盟的后续筹备。有人说过这个建议、人物来援或结缘成功，都还不是这个主线结果。

## 7. 成立后还有哪些时间节点

| 时间 | 重点 |
| --- | --- |
| 第三年十二月中旬起 | 盟务、外交、盟友和防守相关事件陆续推进 |
| 第四年一月上旬 | 进入后续备战阶段；保留一份可回头调整的档 |
| 第四年一月下旬 | 龙湘线若已告白且好感 60，检查该主线的团聚事件 |
| 第四年二月中旬 | 西武林盟决战前夜，整理战力与最终留档 |

**成立资格解决入口，盟友、门派经营与战斗结果影响后面的局势。** 本章不把“出现成立选项”写成保证所有后续战斗获胜。
