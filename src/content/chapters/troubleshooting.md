## 1. 先判断：缺数值，还是缺经历

**缺当前数值，窗口未过时通常还可准备；缺已经错过的剧情、地点或战斗结果，往往必须读早档。** 判断前先看日期、人物位置、心上人，再看好感和战力。

网站自查清单是你手工勾选的记录，不读取游戏存档。勾过一项而游戏没触发时，仍以实际剧情为准。

## 2. 六条路线，按症状排查

| 云裳兄妹没被留在唐门 | 客栈前名声 10；唐门收留群战是否赢 | 客栈救援前；只买药不算收留 |
| 云裳没有接上青城 | 二月是否先留唐门；破庙报信；她在唐门且是心上人，是否走保护受伤 | 第二年二月或危机前，按缺失项决定 |
| 十二月没听到寂灭线索 | 青城经历、她在唐门、医术 3、好感 30 | 第二年十一月末之前 |
| 一月拿不到九转残篇 | 上月线索、青城经历；骰点加好感 80；劝云舟留，先问伤情再问治疗 | 第三年一月讨论前；缺线索则回十二月前 |
| 书在身上却练不了／救不了云裳 | 修炼时佛学 2、心相 60；是否练到 10，学会寂灭三摩地 | 一至四月修炼阶段；不要拖到谷底 |
| 比武后没进云裳谷底 | 她是心上人，好感 50；追人时三次软性对策 | 第三年五月比武前 |
| 谷底救治仍失败 | 武学是否学成，最终好感是否 70，相关战斗与后续 | 谷底前；缺武学要读更早 |
| 师父五月不来 | 是否以师礼正式拜师，好感是否 40 | 第二年拜师或第三年五月前 |
| 师父来过却独自走了 | 是否在唐门会议实际选「雪山行」 | 五月下旬来访后、六月中旬之前 |

| 第二次抵抗灰色 | 传功前是否有饮酒情节 | 备酒与传功前 |
| 第三次抵抗灰色 | 当前心上人是否夏侯兰 | 传功前 |
| 三次抵抗了，仍救不回师父 | 最后骰点 1–50 加好感是否达到 99 | 传功前；好感低于 49 则要更早补好感 |
| 大会后龙湘没留在唐门 | 风波前好感 30，是否明确选「不顾旁人冷眼收留龙湘」并完成返程 | 大会收容选择前 |
| 龙湘没有忧郁 | 第三年九月下旬至十月上旬，好感 40；大会是否去锦香宫 | 大会前；地点选错不能临时补 |
| 龙湘没有觉醒 | 她在唐门、忧郁已触发、后山挑战至少一次 | 十一月中旬至次年一月中旬之前 |
| 龙湘谈话没出现心事 | 是否先谈初识与锦香宫，心上人是否龙湘 | 觉醒谈话前 |
| 打输了龙湘，谈话结束 | 是否选了「我输了，听不得你的心事了」 | 决斗前；输了后选愿意听，仍能继续 |
| 龙湘告白后没团聚 | 好感 60；顽抗十二月下旬、西盟次年一月下旬分别检查 | 对应日期之前完成告白 |
| 小梅没有襄阳同行邀请 | 江陵夜遇是否继续练功；当前好感、暗器互动分流；心上人 | 夜遇前；好感推荐 40 以上留余量 |
| 小梅「我跟你去」不可选 | 心上人是否小梅 | 同行选择前 |
| 小梅被打倒，后续却无法挽回 | 第二场六句唤醒是否真的通过嘴攻说完；只拼伤害不能代替计数 | 第二场失控决斗前，保命并说完野餐末句 |
| 小竹回家请求不出现 | 铁拳门造访 4 次、好感 20、日期窗口、剩余行动 2；或小梅跑步入口 | 第二年四月，或五月下旬至六月下旬 |
| 答应回家却没出发 | 此事件按答应时安排在次旬 | 先等到约好的下一旬，保留旧档 |
| 回家做过，南宫后小竹没留下 | 是否真正返程完成、好感 40、离场是否走关心上官萤支路 | 南宫离场前；缺回家则读更早 |
| 想追小竹，却进入小梅救援 | 是否亲历襄阳，导致救援优先分到小梅 | 襄阳同行选择前，改心上人不能撤销经历 |
| 小竹最终战后没进探望 | 是否进入正确分流，最终金乌决斗是否接到第 15 回合剧情 | 最终决斗前；缺分流则回襄阳同行前 |
| 小师妹主路没有告别 roll | 正常同行迎敌支路不一定经过它；继续检查参战与首胜 | 无需只为看到 roll 回头改线 |
| 小师妹 roll 重掷也不够 | 全部师门负修正、性情处世修正、最高骰点能否够 50 | 用推算工具；不够则回更早准备 |
| 小师妹好感 60 仍未结缘 | 她是否实际参战；金乌第一次决斗是否获胜 | 比武与金乌首战前 |

详细对白和成功标志，以对应人物篇为准。

## 3. 主线与装备的常见误会

| 问题 | 应如何处理 |
| --- | --- |
| 福韫来援，却没西武林盟提案 | 单独来援不等于李富贵遗策。检查李富贵 30＋丐帮 3 或主角自提；魏菊须在集思广益前已在场 |
| 战术不够，以为不能请魏菊提案 | 她在唐门、心相 >20，实际请教即可取得。战术 8／战术 5＋学问 50 影响对白 |
| 魏菊请教项没出现 | 她须在本次集思广益前已在唐门；成立后外交援军来访不能倒补。本书尚未确认决策前到场的稳定走法，不以她兜底 |
| 本场已能访问魏菊，后来选项消失 | 已请教或心相降到 20 及以下；进入讨论前恢复并优先问她 |
| 学问 60 仍不能自提西盟 | 还需金乌已死，战术 5；或者金乌已死、战术 8 |
| 图纸在包里，却不能开发 | 开发的来源项目等级、门派规模和指定解锁物要分别满足 |
| 换装备后旧装备加成没了 | 同类别会替换。不同类别可并存，同类不是叠加收藏 |
| 已结缘小梅，没收到玉霄神匕 | 另查襄阳亲历、好感 50、赠刀时小竹不在唐门及后续转交 |
| 小竹好感高，却没有乌蚕宝衣 | 先在对应窗口去大门做竹之心，再走到辞行留信赠衣 |
| 拿了完竟剑，原武器变了 | 交剑剧情会直接替换当前武器；这是其取得方式 |
| 睡丹有库存，却不能吃 | 服用要求当前剩余行动至少 2，并消耗 1 行动 |
| 没有逆鳞开发，只有大师兄涂鸦 | 检查《十八种奇兵锻法杂记》至少 7；回唐门做锻冶场**劳动**抽制作事件，拿到逆鳞贵重品后才按轻量化 10 开发 |
| 锻冶两次仍没逆鳞 | 资源的 50 是事件抽选权重，不是每次 50% 或两次保底；先确认涂鸦、正确书 ≥7、尚未取得贵重品，再继续劳动 |
| 铁拳留学后仍缺书 | 看书名是否《十八种奇兵锻法杂记》；暴动分支须选认输继续，回家告状会离开赠书链；不是玄兵锻法或火炎山锻谱 |
| 找不到睡丹药方，或以为买全真才给 | 第三年八月会议先成功委托华山求药；十一月起他已归山再问旧事，预留 3,000 打听费。后面 2,000 买全真是可选售书，药方此前已发 |
| 当前有命运 30，却没救大师兄菜单 | 留山运功与随行梦境是不同入口；先查实际去向，不是所有支路都弹许愿。留山看运功入口、内力、救治是否中断，随行看回程结果 |
| 大师兄自然救援后仍有葬礼 | 演出不能直接代替幸存记录；保留救治／回程成功后的档继续后续，别仅因当前葬礼立即判失败 |
| 买齐医书仍来不及过事件 | 修炼点与行动分开算，检查书是否已到给天赋的等级；缺时间回准备期档，按[行动与预算](/guide/resources/)把可选装备顺延 |


## 4. 留档和重掷怎么选

- **数值已够，只差随机点：** 保留判定前档，按可用命运考虑重掷。
- **人物／经历缺失：** 回到对应前置发生前，重做事件；当前界面刷好感通常无效。
- **特定战斗输了：** 回到那一场之前。后面赢了别的战斗，不能替换首战记录。
- **已进入另一主线：** 回到十二月决策。西盟与顽抗的事件日期不同，不能用另一条年表直接判断漏事件。
