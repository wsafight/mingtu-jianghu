# 虞小梅完整路线攻略

> 离线查阅：跨章链接指向《活侠传关键节点选择攻略.md》，请将完整版与本文件放在同一目录。核对资料需保留对应 reference 目录；roll 工具需运行本地网站，公式也可查完整版的小师妹篇。

**小梅线的关键不只有好感。** 本章采用第二年崆峒准备的走法，把小竹回家、主角襄阳同行、五月救援与战斗中的唤醒分别做完，避免临到结尾才发现少了一段经历。

适用本机 **1.0.6000.4**，核对日期 **2026 年 10 月 20 日**。包含必要剧透，身份与结缘结果放在展开区域。

<a id="mei--1-先看整条路线"></a>

## 1. 先看整条路线

1. 第二年二月去崆峒留学，认识飞天门的小梅；本章不照搬云裳的留唐门准备。
2. 留学期间接受她的跑步与玩耍邀请，提高好感；同时去铁拳门认识小竹。
3. 四月，或五月下旬至六月下旬， **小梅好感 ≥20、认识小竹、保留行动**，从跑步进入回家请求。
4. 选 **「追上去看看」**，继续帮忙；有余公子决斗的版本要打赢，答应扮演身份，次旬陪小竹回家并返程。
5. 将心上人设为小梅；江陵夜遇前好感 **至少 35，推荐 40 以上**。
6. 出现 **「回去睡觉」／「再练一下功」**，选后者，继续认出小梅与后续邀约。
7. 出现 **「我跟你去」**，实际同行，并走完襄阳返程，建立主角亲历记录。
8. 第三年五月共同危机选 **「我得去」**，到崆峒救援。
9. 镇魂狱谈话先夸小梅、夸小竹，再谈山中情势，救出两人并继续危机。
10. 后面两场与失控小梅的决斗，保住自己；第二场通过 **嘴攻的六句唤醒对白** 完成唤醒。
11. 收束话题选 **「探望小梅」**，最终选 **「当然，你可以去任何想去的地方」**，确认结缘。

推荐保留五个早档： **崆峒回家请求前、江陵夜遇前、襄阳同行前、五月救援前、第二场唤醒战前**。

## 2. 崆峒怎样认识小梅

第二年二月去崆峒留学，入门与游览过程中，会见到飞天门嫡传女弟子虞小梅，由她带你熟悉环境、介绍自己。

具体留学门派会改变前后对白， **不是只有加入飞天门才能追小梅**。本章需要的是实际认识她、开放相处邀请，再去做小竹回家；不要把“门派名字里有她”当作感情线已经锁定。

初识时她让你叫小梅、她叫你阿活，继续游览与相关入门剧情，不要只看到她露面就跳过这段。

**成功标志：** 她已正式自我介绍，人物关系里能够辨认小梅，并且后面有邀你跑步、玩耍的相处入口。

<a id="mei--3-好感怎么提高跑步有用修仙未必有用"></a>

## 3. 好感怎么提高：跑步有用，修仙未必有用

崆峒期间接受她已经开放的相处邀请。菜单会随事件进度出现 **「今天就跑步吧」**、探险队活动等不同内容，回家前置本章用跑步入口。

| 对应的跑步／玩耍结果 | 小梅好感 | 其他提醒 |
| --- | --- | --- |
| 赛跑，她放慢速度引导你跑完全程 | +1 | 有体魄、轻功等养成收益 |
| 跑着变成聊天、吃烧烤 | +2 | 对应结果花 200 钱、心相 +50 |
| 半路出现少侠，她仍把注意力留给你 | +3 | 属于特定行动结果，不是每次固定 +3 |
| 她破门催你出门玩的结果 | +1 | 继续做完整个相处，不只看邀请 |

**不要把飞天门“修仙”当成刷小梅好感的统一手段。** 已核对的部分修仙结果会扣她 1 或 2 点好感；想走这条线时，要区分你在陪她，还是在做她不认同的事。

好感到 20 后就开始检查回家入口，江陵前再往 40 以上准备。做完行动看实际面板，不把某个高收益随机结果当作稳定产出。

<a id="mei--4-为什么追小梅还要先认识小竹"></a>

## 4. 为什么追小梅，还要先认识小竹

新版共同危机的相关分支会读取 **触发过小竹回家** 的记录。它不是要求你把小竹也攻略完成，而是让你实际参与过她的家事。

去 **铁拳门的大铁铺**，做完初次造访与自报姓名，认识郁竹。不要在唐门普通锻冶场随便工作一次，就认为满足了崆峒铁拳门的相识。

本章建议把回家整段做完。虽然这里部分入口只检查“触发过”，但完成返程既能看清人物关系，也能另存一档转去体验[郁竹线](./活侠传关键节点选择攻略.md#zhu)。

**成功标志：** 你已经认识小梅和小竹，能够接到围绕小竹家事、扮演身份的请求。只让小梅好感到 20，还没有请求记录。

<a id="mei--5-回家请求时间行动与具体选择"></a>

## 5. 回家请求：时间、行动与具体选择

小梅跑步入口的准备：

| 项目 | 要求 |
| --- | --- |
| 日期 | **第二年四月上旬至下旬**，或 **五月下旬至六月下旬** |
| 人物 | 认识小竹，小梅好感 **≥20** |
| 行动 | **至少留 1 行动** |
| 相处入口 | 已开放她的邀请，接受跑步；普通邀请出现也有随机检查 |
| 事件状态 | 尚未触发小竹回家 |

出现选择时，按 **「今天就跑步吧」** 进入对应内容。若此前还没有探险队版本，跑步邀约会以另一组文字呈现；不要选无视她。

接到请求以后，出现 **「追上去看看」** 就追。继续到帮忙扮演公子的商议，答应参与；直接拒绝的 **「不」** 不在本章走法里。

**如果同旬没有触发：** 先查剩余行动和窗口，再查是否已经认识小竹、是否开放小梅邀请。达到好感不保证每次随机邀请都立刻出现，别一直用最后一个行动才去碰。

<a id="mei--6-余公子这一战次旬出发与返程"></a>

## 6. 余公子这一战、次旬出发与返程

小梅发起的回家版本，可能接到与余公子的决斗。 **这一场请获胜**，随后才继续她的易容与扮演安排；战败的玩笑对白“两个都死掉了”，不是本章同一条成功请求流程。

战后有：

> **我答应就是了**／我也想易容

两项都能继续安排。本章选 **「我答应就是了」**；想看易容笑话可以另存体验，不必为此重开整条路线。

答应后，回家行程安排在 **下一旬**，不是所有周目都固定到某月某旬才出发。到了约定时间，跟进她们回家，家中冲突后优先追上小竹，继续到返程结束。

**成功标志：** 旅程收束、回到崆峒养成，完成小竹回家。只答应、只到她家门口，不能算做完了整段。

<a id="mei--7-心上人怎样换成小梅"></a>

## 7. 心上人怎样换成小梅

有意的相处对白累积变心，达到 **10** 后进入相关梦境。描述妻子选：

1. **「应该长得高挑窈窕」**。
2. **「应该算是坦率开朗」**。
3. **「有点疯疯癫癫的样子」**。

需要已经认识虞小梅。如果梦先出现锦囊分岔，选 **「还是先叫媳妇吃饭要紧」** 再进入妻子描述。

**成功标志：** 心上人提示变成虞小梅。江陵夜遇之前就处理好；后面的 **「我跟你去」** 会直接检查，单纯好感 80 也不能替代。

<a id="mei--8-江陵夜遇不要用十月好感-20一句话概括"></a>

## 8. 江陵夜遇：不要用“十月好感 20”一句话概括

这次入口会从江陵相关主线的夜间剧情分流， **不是所有周目只到第二年十月下旬、好感 20，就自动出现同一个邀约**。

提前做两件事： **心上人为小梅；好感至少 35，推荐 40 以上留余量**。夜遇会继续交手与暗器互动，有的分支还会扣好感，要看交手后的当前值。

出现下面两项时选后者：

> 回去睡觉／**再练一下功**

继续夜间练功，接到女飞贼、交手和认出小梅。好感不足可能只得到她威胁将来到唐门找你的对白，随后结束；这不等于已经拿到襄阳同行资格。

**成功标志：** 不只见过女飞贼，而是继续到小梅谈自己的事情，并出现下一节的同行选择。没有同行选项时，回夜遇前查当前数值与心上人。

<a id="mei--9-我跟你去必须亲历并完成襄阳"></a>

## 9. 「我跟你去」：必须亲历并完成襄阳

出现：

> 祝你好运／**我跟你去**

选 **「我跟你去」**。选项可用条件为当前心上人是小梅；前面有关医术、毒术的某些对白检查，与这个选项的心上人检查不是一回事。

| 你的做法 | 后面的记录 |
| --- | --- |
| 选「祝你好运」送她离开 | 这件事触发过，但主角没有亲历襄阳 |
| 点了同行，旅程还在中间 | 还要继续走完整段 |
| 与她同行、经历襄阳内容并返程 | 建立 **主角经历过襄阳行** |

襄阳有城中交涉、冲突与回程，不要把中间某一场决斗的胜负一概当作结缘开关。战前留档，跟进整个旅程，到返回唐门再另存。

**成功标志：** 已实际完成返程。下一年救援检查的是主角的经历，不能靠后来在唐门听她复述补齐。

<a id="mei--10-第三年五月前战斗与好感怎么准备"></a>

## 10. 第三年五月前：战斗与好感怎么准备

这条线后段有连战，资源应优先留给 **活下来、正常输出、能执行战斗行动**。不需要照云裳线去练《九转残篇》，也没有只凭医术很高就替代襄阳的捷径。

本章建议救援前小梅好感 **60 左右或更高**，作为连段对白与互动的余量；这属于推荐准备， **救援准入的关键仍是心上人＋亲历襄阳**。不要把建议 60 误当成能免前置的万能阈值。

小竹也会参与共同救援，可以正常相处、做回家。若还想要小梅赠刀，另外留意第 16 节“小竹不在唐门”的赠刀检查，别把两个人的所有收留都无脑叠上。

**成功标志：** 当前心上人仍是小梅，襄阳已返程，小竹回家前置保留，装备与武学能应付救援连战。

<a id="mei--11-五月共同危机明确选我得去"></a>

## 11. 五月共同危机：明确选「我得去」

唐门比武与来犯者事件之后，会接到崆峒方面的共同危机。小梅线准入要有 **当前心上人小梅＋主角亲历襄阳**；比武后新增的分流还会读取此前小竹回家触发记录。

出现：

> **我得去**／说得也是

选 **「我得去」**。它会扣贡献、向心力及部分师兄好感，是救援的代价；看到负数不必改选接受劝阻。

**成功标志：** 你实际离开去救援，接上郁城、丹霞子及崆峒局面的后续。仅说担心她、听到消息，尚未出发。

没有这组选择时，先查心上人与亲历记录，再查比武后是否保留了回家前置；缺襄阳必须回到前一年的同行，不是五月临时加好感。

<a id="mei--12-镇魂狱先把两人的话题都谈完"></a>

## 12. 镇魂狱：先把两人的话题都谈完

进入镇魂狱相关的谈话菜单，有 **「夸夸小梅」**、**「夸夸小竹」**、**「山中情势」**。

本章顺序为：

1. **夸夸小梅**。
2. **夸夸小竹**。
3. 再谈 **山中情势**，继续荆红到场与劫狱战斗。

如果先谈山中情势、其他话题还没做完，剧情会催你先把前两项说完。它不是让你退出救援去刷好感。

**劫狱时与荆红交手，这一战要获胜。** 胜后有小梅、小竹各加好感的后续，继续到两人脱离囚禁与接下来的危机；不要把出了镇魂狱当作整条感情线完成。

<a id="mei--13-山上分歧与第一场失控决斗"></a>

## 13. 山上分歧与第一场失控决斗

当前心上人为小梅的本章走法，会接到你愿意等她、继续承担崆峒危机的后续。 **不一定看到「我们逃跑吧」的两项菜单**，它在另一心上人分支中出现。

若你确实看到了 **「我们逃跑吧」／「你自己下山，要仔细脚下」**，不要一起逃跑；后者会继续。但也应检查当前心上人是否已被改动，避免照着别人的界面走错目标。

随后接到失控小梅的两场决斗。第一场的任务是 **保住自己并推进剧情**：直接战胜可以继续，撑到第 **8 回合** 的剧情接续也能继续。不要为了追求某个胜负标签故意送死。

**成功标志：** 第一场后有帮助到场，你仍能进入第二场。第二场的唤醒进度会重新开始，第一场嘴攻不能直接当作第二场已经完成的六句。

<a id="mei--14-第二场怎样唤醒让六句嘴攻真正说出来"></a>

## 14. 第二场怎样唤醒：让六句嘴攻真正说出来

**推荐以连续唤醒对白为目标，不要把她迅速打倒就当成完成。** 第二场会给主角专用的唤醒嘴攻：实际执行嘴攻时，按顺序说出六句。

| 次序 | 用来辨认的对白 |
| --- | --- |
| 1 | 「你失了心智，我要怎么帮你？」 |
| 2 | 「不要屈服了，区区的尸心丹！你可是虞小梅！」 |
| 3 | 「我是不会放弃的，你还在这里，我知道。」 |
| 4 | 「我也在这里！还没有死去！」 |
| 5 | 「迟早有一天，再一起去旅行吧。」 |
| 6 | 「不是下辈子……带上食盒，去郊游野餐吧。」 |

**实际说到第六句，会满足唤醒计数并接续剧情。** 看见按钮不算，行动被打断、无法执行时也不能凭点击次数自认已经六次；用出现的对白数来确认。

战前准备保命与气力，战中留意防守、恢复和对方攻势，确保有机会把话说完。第二场有回合推进的负面变化，别一直拖着不执行唤醒，或在前几句之后改成只拼伤害。

只打赢第二场、却没攒够后续所需的唤醒记录，仍可能落到坏收束。 **最清楚的推荐走法就是把六句完整说完，并保持自己没被击败。**

**成功标志：** 看到旅行与野餐的末句，战斗接续到她摆脱控制、崆峒局势翻转的后续。若进入她自伤、无法挽回的段落，读第二场前重做，不只回最后一句选择。

<a id="mei--唤醒战的防守配装"></a>

### 唤醒战的防守配装

在唐门出发救援以前准备 **护心镜 10、医术 3**，有《金钟罩》再练至 10。参考[共用决斗准备](./活侠传关键节点选择攻略.md#combat)取得与学习，别等进镇魂狱后才找地方开发。医术 3 每次备揍回复最大血量 6%，额外代谢毒麻各 15；它比继续加捅人伤害更切合这场的目标。

已经拿到乌蚕宝衣的周目可比较：它加血量 500、双抗各 15；护心镜则兼有备揍减免 50。看自身体力、回血与实战受伤选择，不必为了乌蚕回头改变小竹在场状态。小梅赠刀可留作其他交手用，**六句唤醒不要求高伤害武器**。

<a id="mei--两场分开处理第二场尽早开始说话"></a>

### 两场分开处理，第二场尽早开始说话

1. **第一场：** 先防守观察，血气安全才输出；撑到第 8 回合可以接帮助，不必为速胜耗尽资源。进入第二场重新数六句，不能沿用第一场点击次数。
2. **第二场开局：** 检查当前血量、气力与胆怯。第一场的应对会改变第二场开局，有扣气或胆怯的分支；不要默认每场都会满血满气重新开始。
3. **血量安全时立刻用嘴攻。** 按实际播出的对白数推进一至六。对方捅人会压制嘴攻，胆怯等异常也会影响行动；没播出下一句，就不要把这次点击记成成功。
4. **血量将吃不起下一击时插入备揍。** 利用医术回血、解毒麻，气力够后继续嘴攻；例如「嘴攻两句 → 备揍一次 → 再嘴攻」只是调整示例，受伤过重就先多防一轮。
5. **说到旅行、野餐两句就确认接续。** 第六句建立足够唤醒计数，战斗事件会结束本场并推进。不要在第五句时改用绝招清血条。

**回合为什么紧：** 她的美好记忆回气状态会在第 6、9 回合逐步被移除；第 12 回合转入千灯楼痛苦记忆，第 14 回合出现「一无所有」，第 **15** 回合有尸心蛊反噬，并移除保命的毅力。血量下降也可提前触发对应变化。对她持续猛打、上大量毒再等待，并不比直接说话稳。

建议把六句尽量安排在前半场；中途不得不防守也应持续确认进度，不能误认为拖到某回合便自动救醒。若每次还没说两句自己就倒下，回出发前补防具、医术与基础体力，而不是在同一弱配置下连续抢嘴攻。

## 16. 玉霄神匕、大会同行与主线分别检查

**玉霄神匕** 的赠刀检查需要： **主角亲历襄阳＋小梅好感至少 50＋辞行检查时小竹不在唐门**。她会托三师兄转交，继续到实际领取才算入手。

这与结缘不是同一个时间点。陪小竹回家不会直接等于收留；若为另一条路线把她也带回唐门，会影响赠刀检查，不能只凭小梅好感满了就认定刀必送。

第三年八月武林大会前，若小梅已结缘且在唐门，可继续检查邀请同行的内容。感情线完成后，西武林盟提案与结局仍按主线另外推进。

开发图纸、等级需求与满级效果见[锻造与毒药](./活侠传关键节点选择攻略.md#crafting)。本线不是“每次所有特殊装备都能同时拿满”，先决定是否还要赠刀，再安排兼做的支线。
