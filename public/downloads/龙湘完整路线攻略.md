# 龙湘完整路线攻略

> 离线查阅：跨章链接指向《活侠传关键节点选择攻略.md》，请将完整版与本文件放在同一目录。核对资料需保留对应 reference 目录；roll 工具需运行本地网站，公式也可查完整版的小师妹篇。

**这条线要一直走到告白后的团聚，不能只凭好感或一次决斗判断成败。** 本章从第一年初识写起，采用后期明确收容她的准备走法；已经从其他事件认识龙湘，也可从对应阶段接着查。

适用本机 **1.0.6000.4**，核对日期 **2026 年 10 月 20 日**。含必要剧透，团聚身份揭晓另放在展开区域。

<a id="long--1-先看整条路线"></a>

## 1. 先看整条路线

1. 第一年九月初识事件，继续到雨夜破庙，站在小道长一边，认识龙湘。
2. 提前准备一点解毒常识，顺利处理石灰粉后续；破庙谈话问 **「称谓」**、**「鸡」**，看完相处内容。
3. 日常遇见时相处、做饭，持续培养好感；将她设为心上人。
4. 第三年武林大会行程，明确选 **「前往锦香宫作客」**。
5. 大会风波前好感至少 **30**，她来求助时选 **「不顾旁人冷眼收留龙湘」**。
6. 第三年九月下旬至十月上旬， **好感 40＋锦香宫经历**，实际触发龙之忧郁。
7. 她回唐门后，到后山选 **「我来告诉你，用剑」**，实际挑战至少一次。
8. 觉醒闲谈先问 **「初识之时」＋「锦香宫」**，再问 **「龙湘的心事」**，最后继续 **「心魔」**。
9. 决斗或耐心等她开口的分支通过后，明确告白；好感提前到 **60**。
10. 按顽抗或西武林盟的日期等团聚，完成冲突后的感情收束。

前期认识、锦香宫作客、大会收容、后山挑战、正式告白，都是不同记录。本章会分别给出确认点。

<a id="long--2-第一年初识雨夜破庙怎么走"></a>

## 2. 第一年初识：雨夜破庙怎么走

**第一年九月上旬** 的相关事件会接到捉山鸡、遇雨、到破庙避雨。开始时你在厨房还是后山，会随骰点变化，不必为开头场景强行重掷。

到了破庙，可以按这个顺序选：

1. 出现 **「烤鸡」／「不烤鸡」**，本章选 **「烤鸡」**。
2. 继续公子、小娘子与道士的争执，选 **「小道长，我来助你！」**。
3. 接着交手与冲突，龙湘出面，自报锦香宫身份。

如果选了不烤鸡，后面仍有 **「帮道士」** 的对应入口；但不要把 **「成全苦命鸳鸯，帮公子」** 当成本章同一条走法。

**成功标志：** 已看到龙湘正式自报姓名，并继续到她处理陈公子、石灰粉与守夜谈话。仅听别人提起锦香宫，不等于认识她。

<a id="long--3-石灰粉后续为什么要提前懂一点医毒"></a>

## 3. 石灰粉后续：为什么要提前懂一点医毒

石灰粉这一段有不同受害者与处理结果。想顺利接到破庙相处，提前满足下面任意一项：

| 任意一个可用准备 | 怎么确认 |
| --- | --- |
| **医术至少 1** | 看天赋实际等级；常规医书要练到给医术的等级才算 |
| **门派毒术累计至少 30** | 检查实际毒术积累，不是只看一件带毒武器 |
| 已取得《江湖鬼蜮录》 | 对应的常识检查能辨认，不必三项全做 |

若三项都没有，会进入不懂石灰处理的支路：有的结果使你眼睛出问题，有的让她惊慌跌落山溪。 **跌落山溪的文本后面会说明她活了下来，但你会少掉本章这段顺畅相处。** 不要把所有变体都简单叫作“龙湘当场死亡”。

本章推荐从早期就练出一级医术，或完成对应毒术准备。医书与修炼要求可查[云裳篇的医术准备](./活侠传关键节点选择攻略.md#cloud)，这里只需满足自己的一级检查，不要求云裳线那套医术 3。

**成功标志：** 伤眼问题得到处理，你与她仍在一起，继续守夜和可反复选话题的谈话。

<a id="long--4-破庙守夜怎样成为湘姊的弟弟"></a>

## 4. 破庙守夜：怎样成为湘姊的弟弟

守夜话题菜单里，不要立刻选 **「结束」**。先谈 **「方才的事」**，继续 **「称谓」**，再看开放的话题。

称谓会接到你们交朋友、改用姊弟相称的内容。关于她说相貌“还行”，选 **「你这叫还行而已？你有没有想过我的感受？」**，对应好感 **+1、变心 +2**；若选行走江湖该留心眼，则是另一种性格回应。

有 **「鸡」** 时把这段也谈完。对应做饭后续会按厨艺分流： **厨艺至少 25** 的版本好感 +5，较低厨艺版本也有 +3。不是必须把厨艺练到 25 才能认识她，但这是一笔明确的早期好感。

**成功标志：** 她开始以姊弟相称，你看完烤鸡相处，再从菜单结束守夜。这里的亲近关系有后续对白用途，但仍不是正式恋爱告白。

<a id="long--5-日常怎样培养好感哪些结果确实有效"></a>

## 5. 日常怎样培养好感，哪些结果确实有效

龙湘有不少地点事件，具体出现受她的位置、时期与行动结果影响。采用“出现就抓住，做完看面板”的方法，不要假定每旬都能固定找到同一个选项。

| 日常遇到的内容 | 已核对收益 | 提醒 |
| --- | --- | --- |
| 厨房工作，龙湘来试菜的结果 | 她好感 **+2** | 是这个试菜结果的奖励，并非每次做饭必有 |
| 下山碰上她抓山贼、一起处理 | 相应结果好感 **+1／+2** | 姊弟关系会改变后续与奖励 |
| 她在川泉酒家端菜，你去捧场 | 好感 **+1**、心相 +30 | 相应事件花 **500 钱**，留预算 |
| 忧郁以后在后山挑战，战败 | 对应结果好感 **+1** | 同时积累本线需要的挑战记录 |

本章建议 **大会前先到 40 左右**，这样收容所需的 30、忧郁所需的 40 都有余量。团聚前再达到 60，别把全部提升任务压在觉醒窗口。

前期从大师兄相关出行认识她，也可能经历不同救治、去留内容；那些不是本章破庙初识的统一必做项。无论从何入口结识，后面都按实际在场和收容记录检查。

<a id="long--6-心上人怎么设为龙湘"></a>

## 6. 心上人怎么设为龙湘

有关她的有意对白累积变心，达到 **10** 后触发相应梦境。梦中描述妻子选：

1. **「应该长得高挑窈窕」**。
2. **「应该算是坦率开朗」**。
3. **「有点呆」**。

需要已经认识龙湘。若梦境先问锦囊与叫媳妇吃饭，选 **「还是先叫媳妇吃饭要紧」** 再进入妻子描述。

**成功标志：** 心上人提示变为龙湘。觉醒菜单开放 **「龙湘的心事」** 时会实际检查；仅仅湘姊好感最高、你们姊弟相称，都不能代替。

<a id="long--7-武林大会行程明确去锦香宫作客"></a>

## 7. 武林大会行程：明确去锦香宫作客

第三年出门参加武林大会的行程讨论里，可以听同门与各人的意见，最后要实际选择：

> **前往锦香宫作客**

**「龙湘的意见」只是讨论话题，不等于已经选定行程。** 委任师弟、自己独行江陵是另一条路线，不能靠后来听到锦香宫消息补成同一经历。

选择以后，继续船行与作客剧情，直到实际到了锦香宫。留一份大会行程讨论前档，后面忧郁没触发时就有地方检查。

**成功标志：** 主角确实走完这次锦香宫作客安排。她说要回锦香宫、曾经来自锦香宫，也都不是主角的这项经历。

<a id="long--8-大会风波怎样明确收容她"></a>

## 8. 大会风波：怎样明确收容她

大会风波中， **龙湘好感至少 30**，会有她来到唐门众人这边，想暂时留下、又怕连累你们的场面。此时选：

> **不顾旁人冷眼收留龙湘**

这项建立 **唐门收容龙湘** 的记录，并增加她好感 **3**。另一项 **「局势未明了，避免连累师门，先不表态」** 不会建立同样的收容记录。

随后继续整个大会与返程流程。后期是否让她加入、留在唐门，会读取这项收容记录；不能只凭早年她来唐门吃过饭认定人已经留住。

**成功标志：** 她向唐门众人道谢，接受暂留，之后返程安排里能保住她在唐门的状态。若根本没有出现求收容场面，先查当时好感是否到 30。

<a id="long--9-九月下旬至十月上旬实际看到龙之忧郁"></a>

## 9. 九月下旬至十月上旬：实际看到龙之忧郁

检查窗口为 **第三年九月下旬至十月上旬**，需要：

- 龙湘好感 **至少 40**。
- 前面的武林大会行程实际选择并完成 **锦香宫作客**。

看到对应忧郁事件之后，才继续后山挑战和觉醒。好感够高不代表这件事已经发生；错过窗口后临时换心上人，也补不回此前的行程。

**没出现时的回档顺序：** 先读窗口前查好感，再读大会行程前查目的地。如果没有锦香宫经历，不要在后山空耗数旬指望系统补发。

<a id="long--10-后山挑战选我来告诉你用剑"></a>

## 10. 后山挑战：选「我来告诉你，用剑」

忧郁以后她在唐门时，到后山遇见她练剑。出现：

> 「让她静一静」／**「我来告诉你，用剑」**

本章选择后者，实际进入挑战。 **至少挑战一次**，才满足后面觉醒的这项前置；仅走到后山看她一眼不算。

这次检查的是挑战次数， **不要求挑战取胜**。战败也能继续，并有对应好感奖励。它与之后“龙湘的心事”中的谈心决斗是两场不同的事。

**成功标志：** 确实打完这次后山决斗，回到养成。打不过她也别因此放弃整条线。

<a id="long--11-觉醒窗口先确认时间和人都对"></a>

## 11. 觉醒窗口：先确认时间和人都对

觉醒检查在 **第三年十一月中旬至第四年一月中旬**，需要：

| 要求 | 你应检查的事实 |
| --- | --- |
| 龙湘在唐门 | 大会收容与后续返程确实完成，当前没有离场 |
| 忧郁已经触发 | 看过第 9 节事件，而非只有好感 40 |
| 后山至少挑战一次 | 第 10 节实际进入战斗 |

**走顽抗时，建议十一月就处理觉醒与告白。** 不能看到窗口可到第四年，就把后面的第三年十二月团聚也拖过去。

觉醒前另存一档。接下来有反复选话题的菜单，选择结束会收掉整场，不是随时可以再聊。

<a id="long--12-觉醒谈话四个话题依次做完"></a>

## 12. 觉醒谈话：四个话题依次做完

按这个顺序点：

1. **初识之时**。
2. **锦香宫**。
3. 前两项谈完、当前心上人是龙湘，选择 **龙湘的心事**。
4. 按下一节处理她开口的分支，回到菜单以后，继续 **心魔**。

**不要在只谈完前两项时就选「结束闲谈」。** 结束会清掉本场事件，不能把“我见过心事选项”当成已完成谈心。

若心事没开放，查当前心上人及两项是否都真的选过；若心魔没开放，查心事分支是否接到她愿意说的后续。不要去刷另一个后山挑战替代这场对话。

<a id="long--13-决斗输了怎么接高修养又怎么过"></a>

## 13. 决斗输了怎么接，高修养又怎么过

**修养不高于 40** 的直接分支中，推荐选 **「真拿你没办法（决斗龙湘）」**。

| 结果 | 接着做什么 |
| --- | --- |
| 决斗获胜 | 她愿赌服输，继续听心事，再回菜单谈心魔 |
| 决斗战败 | 选 **「既然我输了，只好按照约定听你说了。」**，继续听，再谈心魔 |
| 战败后选「我输了，听不得你的心事了」 | 本场结束；想按本章走应读谈话前档 |

**修养高于 40** 时，会改成耐心等她开口的分支。对应判定为：

```text
基础骰点 1–70 ＋ 龙湘好感的 50%（按游戏取整） ≥60
```

达到后接到 **「我想说，现在就想说」** 的后续，再回菜单谈心魔。比如好感 60 贡献 30 分，基础骰点至少要 30；好感 80 贡献 40，基础至少 20。

没有直接决斗选项本身不代表失败，也不必专门把修养压低。 **关键是她愿意开口、你继续谈心魔。** 本章不把「不了我不问了」的其他数值变体作为统一安全答案。

<a id="long--14-明确告白好感提前到-60"></a>

## 14. 明确告白，好感提前到 60

心魔对话推进后，按你看到的版本，选择明确说心意的回答：

> **我有心上人，就是你。**  
> 或 **比起吃的，希望你知道我的心意。**

**成功标志：** 你已清楚表白，她需要时间考虑，建立正式告白记录。打赢、打输谈心决斗，她叫你弟，或她心情好，都不能代替这句话。

告白后不要急着改追别人。团聚还检查 **龙湘好感至少 60**，应在团聚日期到来前准备好；告白本身没有替你免除好感检查。

<a id="long--15-团聚日期选战与成功标志"></a>

## 15. 团聚日期、选战与成功标志

| 你的主线 | 团聚检查时间 | 提前完成 |
| --- | --- | --- |
| 顽抗 | **第三年十二月下旬** | 正式告白＋好感 60 |
| 西武林盟 | **第四年一月下旬** | 正式告白＋好感 60 |

团聚中有两种战斗选择，别把某一次输赢套在整条线所有战斗上：

| 选择 | 后续差别 |
| --- | --- |
| **「湘姊，我们连手揍他」** | 合战支路；胜败对白不同，之后都可继续相认与谈话链 |
| 「湘姊，让我帮你报仇」 | 单独上前；获胜可继续相认，战败会转入另一段包扎与感情收束 |

本章推荐先体验 **联手**，战前留档即可；不需要为追求“每战都赢”反复覆盖之前的告白档。

### 龙湘团聚与结缘的最终确认

联手的后续会进入父女相认。继续看完龙渊与龙湘的谈话，话题菜单中把开放的 **「守信用」**、**「隐姓埋名的理由」**、**「方今局势」** 等内容谈下去，再接 **「拜堂」** 的感情收束；不要刚认出身份就停下。

继续到两人关系明确、建立结缘的后续，才算完成。父亲要求将来练好武功再来较量，是后续约定；不是让你先练到全属性满值才承认这段关系。

若采用单独上前的战败支路，会接到包扎和两人感情明确的另一种收束，不必为了看父女相认版本把它误判为整线无效。

<a id="long--16-留档与断线排查"></a>

## 16. 留档与断线排查

| 卡住的位置 | 优先检查 | 应保留的早档 |
| --- | --- | --- |
| 破庙后没相处 | 医毒常识、是否帮小道长、石灰粉后续 | 第一年九月初识前 |
| 大会没求收容 | 当时好感是否至少 30 | 大会风波前 |
| 后期她不在唐门 | 是否选过公开收留，并完成返程 | 大会收容选择前 |
| 忧郁没发生 | 好感 40＋主角锦香宫经历＋日期窗口 | 大会行程前、九月前 |
| 觉醒没来 | 她在唐门、忧郁、后山实际挑战 | 后山行动前、十一月前 |
| 心事或心魔锁住 | 心上人、前两个话题、愿意听心事的后续 | 觉醒闲谈前 |
| 团聚没来 | 正式告白、好感 60、当前主线的日期 | 告白前、对应团聚旬前 |
