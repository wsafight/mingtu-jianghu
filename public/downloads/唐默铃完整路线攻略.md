# 唐默铃完整路线攻略

> 离线查阅：跨章链接指向《活侠传关键节点选择攻略.md》，请将完整版与本文件放在同一目录。核对资料需保留对应 reference 目录；roll 工具需运行本地网站，公式也可查完整版的小师妹篇。

**本章把小师妹线拆成可跟着做的阶段，也说明师门好感的扣分规则。** 顺利进入她同行迎敌的支路时，不一定遇到告别 roll；遇到它时，则必须按所有修正后的总分判断。

适用本机 **1.0.6000.4**，核对日期 **2026 年 10 月 20 日**。包含必要剧透，结缘收束可展开阅读。

## 1. 先看整条路线

1. 前两年持续与小师妹相处，遇到烤鱼、玩水等内容就陪她，不要到招亲才补好感。
2. 保持 **心上人为小师妹**；若曾变心，提前通过梦境换回。
3. 第三年四月婚嫁讨论，选 **「抗议」** 表态，继续夜访谈话。
4. 比武前把好感准备到 **至少 60**，心相准备到 **至少 65**，并保留一份战斗装备。
5. 出现 **「跳上屋顶去观战」** 时选它，观战途中本章选 **「不赌」**，保住小师妹好感。
6. 跟进山下四师兄遇袭的主线；她来找你，要确认两人实际一同下山迎敌。
7. **五月迎战时第一次决斗金乌上人获胜**，这次记录不能用后面补赢代替。
8. 若中途接到告别、放手的 roll，争取总分 **≥50**，得到 **「小师妹是我的！」** 的后续。
9. 收束时同时满足 **她好感 ≥60、她实际参战、你金乌首战获胜**，继续明确结缘。

留档时把“五月比武前”和“金乌首战前”分开。你需要能改前置的早档，也需要能重打战斗的近档。

<a id="sister--2-第一二年怎么培养好感"></a>

## 2. 第一、二年怎么培养好感

小师妹开局就已认识，不需要像云裳一样先做收留。难点是把日常好感留出来，同时别让其他养成挤掉所有相处行动。

| 日常遇到的内容 | 本章做法 | 对应收益 |
| --- | --- | --- |
| 后山遇到小师妹想吃烤鱼 | 选 **「捉鱼时间」** | 对应相处好感 +2、心相 +20 |
| 小师妹与云裳一起邀你玩水 | 选 **「玩水时间」** | 两人各好感 +2，另有心相恢复 |
| 厨房工作，小师妹来代班的结果 | 做完这次厨房相处 | 对应结果小师妹好感 +2 |
| 下山遇到纸艺人，买纸雕带回家 | 完成该闲逛结果 | 花 200 钱，小师妹好感 +2 |

这些是 **出现对应事件／行动结果时** 的收益，不代表点一次厨房或后山就保证刷到。平时做完检查人物面板，以实际增加为准。

**本章建议五月前到 60，并留一点余量。** 60 是后面检查的最低值；如果临近节点前又扣了两点，就不能拿此前见过 60 当通行证。

<a id="sister--3-后山烤鱼具体怎样选"></a>

## 3. 后山烤鱼具体怎样选

后山练功等行动有机会遇见她：没有云裳在旁时，她会用眼神暗示想吃烤鱼，出现：

> **捉鱼时间**／不能让这家伙打乱计划

选第一项，继续捉鱼、烤鱼。若云裳也在，会换成：

> **玩水时间**／不能让这两个家伙打乱计划

一样选陪伴。第二项是照原计划继续养成，不是暗藏的“欲擒故纵加好感”。

**成功标志：** 看见相处结果，小师妹好感确实增加。是否收留云裳会影响对白与同行人数，不要求为了追小师妹必须先完成云裳整条线。

这些恢复心相的日常也有养成价值，但不要为等同一随机事件一直空转；有练功和备战需求时正常分配行动。

<a id="sister--4-心上人开局就是她变心后怎样换回"></a>

## 4. 心上人：开局就是她，变心后怎样换回

如果你一直没改过，初始心上人就是小师妹，无需额外做梦确认。 **好感最高者不一定是心上人**，曾追过师父、小梅等人时要特别检查。

通过变心达到 **10** 触发的梦境，描述妻子选：

1. **「应该长得娇小玲珑」**。
2. **「应该算是恬静温驯」**。
3. **「那姑娘有一颗无垢之心」**。

若先遇到锦囊分岔，选 **「还是先叫媳妇吃饭要紧」**，再接妻子描述。

**成功标志：** 游戏的心上人提示是小师妹。四月婚嫁前、五月比武前都看一次；临到最后才改，不能倒补此前已走错的分支。

<a id="sister--5-第三年四月婚嫁讨论选抗议"></a>

## 5. 第三年四月：婚嫁讨论选「抗议」

第三年四月进入婚嫁讨论，出现 **「保持沉默」／「抗议」**，本章选：

> **抗议**

这是一项明确表态，会付出贡献与师兄好感等代价，并有小师妹好感收益。不要因为看到扣贡献，就把它当成“攻略失败警告”。

但抗议也不等于她立即取消婚约，更不等于已经结缘。继续看后面筹办、谈话与夜访，不要只保留抗议后的档，覆盖四月之前的准备档。

**成功标志：** 你实际参与了反对讨论，主线继续。此时仍要准备五月观战、迎敌和首战。

<a id="sister--6-夜访怎么聊不是一个选项立刻锁定结缘"></a>

## 6. 夜访怎么聊：不是一个选项立刻锁定结缘

夜里小师妹来找你的对白，会随 **好感至少 50＋心上人为小师妹** 进入较亲近的分支；其他人物在不在场也会改变开头。

问她来做什么时，有：

| 选项 | 这段内容怎样理解 |
| --- | --- |
| **「你饿了」** | 本章推荐体验，继续烤鱼、照顾她；不同厨艺有不同结果 |
| 「你睡不着」 | 另一段陪伴与谈话，不是自动放弃 |
| 「你怕嫁了以后见不到我」 | 更直接谈及不舍，继续看她的回应；不能只凭一句对白判断结缘 |

想按本章稳妥推进，先走 **「你饿了」**，把整段看完即可。这里不要求三项都各选一次；与龙湘觉醒那种可反复话题菜单不同。

**成功标志：** 夜访收束，继续五月之前的主线。她来夜访或说舍不得你，仍不能代替实际参战和金乌首战获胜。

<a id="sister--7-五月比武前心相-65-要留到选项出现时"></a>

## 7. 五月比武前：心相 65 要留到选项出现时

出现 **「跳上屋顶去观战」** 时，可选条件是 **当前心相至少 65**。刚好 65 可以；如果前段剧情消耗后只剩 64，之前曾经满心相没有用。

本章建议比武前恢复到较高水平，并另存一档。不要在最后一旬把练功行动用到心相很低，再指望剧情自动回满。

| 准备项 | 用在什么地方 |
| --- | --- |
| 心相 ≥65 | 屋顶观战选项 |
| 小师妹好感 ≥60 | 后面的结缘检查，也有助于相关 roll |
| 当前心上人为她 | 夜访与同行迎敌的正常支路 |
| 可用的武学与装备 | 金乌第一次决斗，不只是招亲现场观众比武 |

**成功标志：** 观战选项能点，你实际跳上屋顶继续剧情。只在附近看热闹，不能默认走了相同流程。

<a id="sister--8-观战中别为赌钱扣掉好感"></a>

## 8. 观战中别为赌钱扣掉好感

屋顶观战时会有同门赌输赢的内容。出现 **「赌」／「不赌」**，本章建议：

> **不赌**

参赌支路会扣小师妹、掌门和三师兄的好感；后面的输赢决定钱，而不是撤销此前的关系代价。选择不赌还有对应武学点收益。

因此，想走小师妹线时，不必为了“可能赚钱”去增加一次数值波动。其他人物对擂台的胜负、剧情里的观众押注，也不是你自己的金乌首战结果。

**成功标志：** 正常继续比武与四师兄遇袭的后续，小师妹好感维持在准备好的范围。

<a id="sister--9-她实际参战看见两人一同下山"></a>

## 9. 她实际参战：看见两人一同下山

山下四师兄遭遇麻烦，唐门弟子去助阵，小师妹会来找你。 **当前心上人为她** 的正常支路，会继续到她坚持陪着你、你带她下山的后续。

可用的确认对白包括你说：

> **小师妹，我们一同下山，助四师兄退敌。**

没有瑞笙同行时，会是你带她一起赶回去的另一段对白。无论具体版本， **要确认她真的随你去迎敌**，不能把她只在相亲现场出现当参战。

**成功标志：** 她参加对抗来犯崆峒一方的迎战，后面仍在相关战斗与对话里。若你坚持把她送回去，先检查当时是不是已经改了心上人。

修养、口气和其他同伴会改变这段战斗的表现。不要把金乌激将时“修养 <80”的对白条件误写成她参战的统一门槛。

<a id="sister--10-金乌首战这场必须打赢"></a>

## 10. 金乌首战：这场必须打赢

本章所说的首战，是 **第三年五月迎战崆峒这一段、第一次决斗金乌上人**，不是更早遇见他时的交手，也不是后期再去崆峒的大战。

在这一次决斗 **开战前另存**。胜负会单独记录，后面再打赢一场无法覆盖本次战败。

| 看到的情况 | 应怎样处理 |
| --- | --- |
| 这次获胜，并继续师兄、小师妹对话 | 保留胜利档，继续收束 |
| 这次战败，后来还有别的战斗 | 想照本章走就读回首战前，不要把补赢当相同记录 |
| 能赢但她没参战 | 回第 9 节检查分流，胜利本身补不了她在场 |
| 经常差一点伤害或先被打倒 | 回比武前调整武学、装备和战法，再打这场 |

装备可查[锻造与毒药](./活侠传关键节点选择攻略.md#crafting)。近战武器同类别会替换，不是把所有图纸开发一遍就叠满伤害。

<a id="sister--首战前的实际配装与武学顺序"></a>

### 首战前的实际配装与武学顺序

还在第三年四月能养成时，先按[战斗准备](./活侠传关键节点选择攻略.md#combat)做 **护心镜 10＋医术 2–3**，再补 **菁英小剑 10**。只用基础武器、把钱全花到多条暗器树上，通常不如先补这两件直接。尚未达到规模 2 时，优先强化唐门制服与小剑，另留能补规模、点数的准备期档。

武学优先医书，然后是已经到手的《金钟罩》；已有《南宫心法》再加护心诀保险。**不要把小梅赠刀、乌蚕或完竟剑列成这场战斗的必备品**：它们各有额外事件，有的在此战以后，取得也未必符合你的路线。

<a id="sister--开局蓄力与收尾怎么打"></a>

### 开局、蓄力与收尾怎么打

| 阶段 | 操作例子 | 看什么再改打法 |
| --- | --- | --- |
| 前两轮试探 | 先用一次备揍／金钟罩，观察受伤、回血和气力；有余量再捅人输出 | 若防守仍被打掉大量血，回准备期补防具与医术；近档只重掷出招并不能补强 |
| 正常交手 | 血量安全时用捅人消耗；敌方铁琵琶功防守明显时少硬捅，可用现有暗器周旋 | 敌方备揍不是无风险白送回合，铁琵琶有反制；看状态说明与实际结算 |
| 自己血量下降 | 提前插入一至数次备揍，借医术回血、代谢毒麻，再恢复攻击 | 回血在结算后，不能等只剩一击可承受时才开始；胆怯影响回气时尤其保守 |
| 对手有大招气力 | 保持血量余量、优先防守；没把握就不要连按捅人 | 捅人与暗器会受对方绝招压制；不能把对方满气当成普通输出窗口 |
| 对手血量接近收尾 | 有安全血量和气力才用高伤害招式结束，气不够就继续攻防循环 | 这一场的目标确实是获胜，不能套用小竹的「等第 15 回合」 |

这里没有固定十五键按法：敌人出招随机，赵活的性情、武学与气力也不同。修养至少 **40** 时，首战第 5 回合或敌方血量降到一半的激将后续有 **我方气力 +30** 的分支；低于 40 则可能被挑动并给敌人补气。**这是战斗调节建议，不是小师妹参战门槛**，不要与前文修养 80 的其他对白混淆。

**确认结果：** 战后这次确实判胜，再保存「五月金乌首胜」。本场战败即使故事继续，也应读回重打。若反复打不过且已到近档，只能回四月准备期调整；不建议靠追求全属性满值才能继续。

<a id="sister--11-哪些时候会遇到告别-roll"></a>

## 11. 哪些时候会遇到告别 roll

部分告别、准备放手的支路会出现争取她的 roll。 **这不是所有成功走法都必经的固定一关**，所以正常同行迎敌时没看见它，不要特地回头把顺畅主路改坏。

如果你已经遇见这次判定，按最终总分区分：

| 含修正后的总分 | 结果 |
| --- | --- |
| <50 | 「割舍心」，走向放手 |
| **≥50** | **「小师妹是我的！」**，继续争取的后续 |

它是骰点结果，并非平时菜单中随时能点的告白按钮。过这次 roll 之后，仍要继续检查你所在支路的参战、首战与收束；不能把一个高骰当作全线前置补齐。

<a id="sister--12-大师兄好感确实扣分完整修正怎么看"></a>

## 12. 大师兄好感确实扣分：完整修正怎么看

小师妹好感加分，师门几位长辈与师兄好感在这次告别判定中扣分：

| 项目 | 对最终总分的贡献 |
| --- | --- |
| 随机骰点 | **1–99** |
| 小师妹好感 | **+好感的 100%** |
| 大师兄、二师兄、三师兄、掌门好感 | **各扣好感的 30%** |
| 四师兄好感 | **扣好感的 20%** |
| 性情、处世 | 按各自性格档位修正；不是把面板值直接相加 |

游戏对每项修正分别取整，以判定界面实际显示为准。比如大师兄好感 100 扣 30，40 扣 12；其他条件相同，前者难 **18 分**。

**没有“大师兄好感超过某值就永久锁死”的独立上限。** 应看所有加减项之和：小师妹和性格加分可以抵消，负修正过大也可能使最高骰点都不够。

你可以直接使用本书的[小师妹 roll 推算](http://127.0.0.1:4321/tools/roll/)，输入当前数值，看最低需要多少基础骰点。

<a id="sister--13-怎样判断该重掷还是该读早档"></a>

## 13. 怎样判断该重掷，还是该读早档

先把判定界面的全部固定修正合并，记作「净修正」。本次最低基础骰点为：

```text
最低基础骰点 = 50 − 净修正
```

| 净修正示例 | 最低基础骰点 | 该怎么做 |
| --- | --- | --- |
| +10 | 40 | 有机会；可留档重掷 |
| −20 | 70 | 有机会，但比上一种更难 |
| −49 | 99 | 只有最高基础点可过 |
| −50 | 100 | 超出 1–99；只重掷无效 |

这些是 **净修正示例**，并非某套人物面板的固定结果。性格与所有师门好感都要一起算。

如果最高也不够，就读到仍能培养小师妹、调整性格和行动分配的早档。 **不要为了少扣大师兄好感，直接放弃救他。** 他的生死、主线影响，与这次扣分不是一回事；也不需要把全体师门好感故意降到零。

## 14. 最后怎样确认确实结缘

1. **小师妹好感至少 60**。
2. **小师妹实际参加五月迎战崆峒**。
3. **你赢下该段第一次决斗金乌上人**。

### 小师妹结缘的最终确认

继续到两人明确关系的后续，小师妹回应已经到家、哪里也不去，才是本章要的结果。她之前的夜访、拍肩或跟你下山，都只是前面的阶段。

## 15. 结缘后与这一周目的主线安排

小师妹这条感情线与西武林盟并非互相替代。五月完成结缘之后，还要继续大师兄生存、大会、唐门决策等主线。

想强度优先，优先保证能赢关键决斗，再分配书籍、开发和师门资源。 **没有为了小师妹必须把某一项战斗属性刷到 100 的统一条件**；她这条线明确检查的心相、好感、参战与首战应分别满足。

特殊装备的来源另见[锻造与毒药](./活侠传关键节点选择攻略.md#crafting)，大师兄生存查[师门风雨](./活侠传关键节点选择攻略.md#branches)。不要在婚嫁节点前临时把所有钱都用来开发暂时无用的项目。
