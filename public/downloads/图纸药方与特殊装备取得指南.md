# 图纸药方与特殊装备取得指南

> 离线查阅：跨章链接指向《活侠传关键节点选择攻略.md》，请将完整版与本文件放在同一目录。核对资料需保留对应 reference 目录；roll 工具需运行本地网站，公式也可查完整版的小师妹篇。

**找一件装备从哪里来，先查本章；比较需求、花费和满级效果，再查[锻造与毒药](./活侠传关键节点选择攻略.md#crafting)。** 六条路线可取得哪些、哪里有分流冲突，集中在第 4–5 节。

适用本机 **1.0.6000.4**，核对日期 **2026 年 10 月 20 日**。各事件按实际窗口、人物在场和任务状态检查。

## 1. 获取场景与选择

本节列已核对的获取场景，供你提前留档。**开发的硬条件以[锻造与毒药的各类别需求表](./活侠传关键节点选择攻略.md#crafting)为准**；取得贵重品后，还要满足开发表中的前置等级和门派规模。

| 乌蚕宝衣 | 第二年十一月上旬至十二月上旬，小梅、小竹都在唐门、小竹好感至少 50，去大门做成「竹之心」；之后小竹辞行留信赠衣 | 护心镜 10 → 乌蚕宝衣 |

<a id="recipes--2-逆鳞宝衣从第一年开始怎样安排"></a>

## 2. 逆鳞宝衣，从第一年开始怎样安排

**这是一条「涂鸦 → 书 7 级 → 锻冶劳动 → 再开发」的链，和小竹结缘分别检查。** 本节采用已追通的铁拳留学赠书入口；未把其他可能的购书或替代来源当作已验证方案。

| 步骤 | 什么时候、去哪里、怎样选 | 当场成功标志／漏了怎么办 |
| --- | --- | --- |
| 1. 拿涂鸦 | **第一年四月上旬至五月下旬**，心相 **≤30** 时留意休息、大师兄找你消遣的事件。骰点 **>60** 接到琴棋书画、肩甲讨论；谈肩甲选 **「啊，我好像懂。」**，继续机关甲衣的话题 | 贵重品得到 **「大师兄的涂鸦」**。选「人家只不过穿体面点，何必呢？」是在支持肩甲，接不到同一张图；骰点 21–60 打山贼、≤20 上屋顶。保留窗口前与骰点前两份档 |
| 2. 拿正确的书 | 第二年二月去**崆峒铁拳门**。入门风波骰点 **<50「忍辱负重」**，继续留下；若掷到 ≥50「参与暴动」，接下来选 **「我认输，不要打我。」**，不要选回家告状 | 雷谦赠 **《十八种奇兵锻法杂记》**。它不是《崆峒玄兵锻法》，也不是《火炎山锻谱》。想拿这本，二月分门前先存档 |
| 3. 读到 7 级 | 得书后安排修炼。每级 5 修炼点，0→7 共 **35 修炼点**，无额外学习门槛；这七级另累计给 **35 锻造点** | 秘籍面板显示 **7 级或更高**。两种点数分别计，不能把获得的锻造点直接当成书已学完 |
| 4. 回唐门做劳动 | 同时持有涂鸦、书 ≥7，且尚未取得逆鳞宝衣时，去**锻冶场劳动**。继续抽到大师兄机关甲衣的特殊工作事件，演出中与小竹一起制作 | 收到 **「逆鳞宝衣」贵重品**及防具解锁提示。单开开发菜单、反复强化别的衣服不等于劳动抽事件 |
| 5. 真正换装 | 唐门制服 **5** →轻量化（规模 **2**）；轻量化 **10** →逆鳞（规模 **1**，持有刚取得的贵重品），再投入强化 | 当前防具栏是逆鳞宝衣。它本体 0→10 另要 **85 锻造点、4,250 钱**，不含上级投入和返还 |

**劳动事件还要抽选。** 资源配置的 50 是和其他可用工作事件共同参与抽取的权重，不等于每次固定 50%，也不保证做两次就出现。该事件的激活条件只检查书等级、涂鸦与尚未取得逆鳞，**没有额外要求已与小竹结缘、她好感多少或已正式收留她**；不要把演出人物自行添成隐藏硬门槛。

逆鳞满级给决斗捅人 +15、暗器 +20；战役防御 +2、反伤 +5。想撑金乌回合时仍应比较护心镜的血量、备揍减免，不能将战役反伤误用成决斗机制。

第一年漏涂鸦，要回第一年事件窗口；二月去了夺魄门或留唐门，本节的**铁拳赠书入口**就无法在当前安排中补做。云裳青城、师父夺魄都有核心分流，不建议为了这件衣服改坏主线。小竹线可将铁拳作为留学分门选择，但「加入铁拳得书」与「访问铁铺认识小竹」仍是两项不同经历。

<a id="recipes--3-睡丹药方八月委托归来后才取方"></a>

## 3. 睡丹药方：八月委托，归来后才取方

前期恢复心相可先用已开放的成品、饮食或休息，**不要把睡丹当作云裳一至四月修炼的必备资源**。它的已核实入口在更晚的四师兄远行：

1. **第三年八月上旬唐门会议**，查看四师兄远行话题，选 **「故意提出一些难办的要求」**。若本周目成为崆峒掌派人、而四师兄好感低于 60，他会先拒绝；想走此入口应在会议前准备好关系。
2. 常规接受判定为 **基础 1–70＋四师兄好感 ≥70**。过关后在指定请求中选 **「听说华山有神仙，而神仙有灵丹」**，建立求药委托。询问小师妹近况是另一份委托，不是同一药方前置；未接受的半价售货分支也不等于已经托付求药。
3. 等远行与返山后续走完。**第三年十一月上旬起**，四师兄已回唐门、委托仍有效时，在弟子房问 **「以前托你打听的事」**；不按“过一旬就送方”计算。
4. 他要 **3,000 钱打听费**。建议预留足额；不足会收走现钱并以贡献抵差，部分档位还扣好感。曾被金乌敲头失忆的分支，汇报会再出现 <50／≥50 的随机分流；要取药方须接到华山求药的汇报，领到后核对贵重品。
5. 看到仙丹已被求走、他交出药方，实际获得 **睡丹药方**，再到炼丹房开发。后面另问 **2,000 钱**买的是 **《全真天遁剑典》**（要求四师兄好感至少 50 才谈售书），拒买不影响此前已经发放的药方。

**其他日期也按真实入口读。** 切鱼刀看六道法王话题是否已开放，传承小剑有多条授剑／寻剑入口，万灵油随捕获、处置唐守鸿的后续任务排期；这些不能统一写成某个默认日期必给。纸甲与猛火图纸则明确是在八月中旬整理书楼，同一次事件只给一种。

## 4. 按六条线路看，这一周目能拿哪些

先记两个合并名单，下面每行都按这两个名单展开规划：

- **通用三项**：切鱼刀、唐门传承小剑、睡丹药方。获取事件不以最终结缘对象为条件，六条线都可规划；仍需分别完成谈话骰点、授剑或寻剑、委托四师兄寻药。**其中睡丹最早规划委托是第三年八月，归来后才领方，不是早期资源。**
- **留唐门二选一**：纸甲图纸／猛火油柜图纸。要实际走到上表的唐门夜袭、整理藏书事件，并取得对应骰点结果；同一次事件只给其中一张。选择崆峒留学的走法，不把这两张预设成必得。

<a id="recipes--5-跨线能否兼拿按这些条件判断"></a>

## 5. 跨线能否兼拿，按这些条件判断

| 物品 | 跨线判断 |
| --- | --- |
| 牛皮制服、金钱剑、万灵油药方 | 关键是**青城经历及各自事件**。本书将它们放在云裳推荐路线；它们并非只在结缘成功后才发。其他线路没有做这段青城经历时，就不能照这份来源表默认能拿；金钱剑和万灵油还各有额外条件 |
| 密密缝 | 关键是**拜师后的补衣事件**（一月切磋后续，或雪山传功后续），不是最终结缘判定。额外走到对应补衣剧情，可能在其他结缘计划中取得；但要先核对五月之后的事件排期，云裳推荐走法不能直接拿「二月崆峒拜师」替换青城前置 |
| 玉霄神匕 | 赠刀条件是**襄阳亲历＋小梅好感 50＋当时小竹不在唐门**，没有额外检查必须已经与小梅结缘。其他线要兼拿，也得真的满足这三项；小竹专线会与本书避开襄阳的安排冲突 |
| 乌蚕宝衣 | 关键是先完成**竹之心**，再走到辞行赠衣。竹之心相关出门事件检查小梅、小竹都在唐门、**小竹好感至少 50**；完成后还要等后面的赠衣剧情。它不是只属于「已经与小竹结缘」的奖励 |
| 沥泉枪头 | 关键是**叶云舟同行武林大会、好感至少 40**。发放分支没有要求云裳一定同行，也没有要求心上人必须是云裳；所以其他线路也可按这些条件规划 |
| 逆鳞宝衣 | 关键是**大师兄涂鸦＋《十八种奇兵锻法杂记》≥7＋唐门锻冶劳动抽事件**，再走轻量化 10 开发。没有结缘要求；本节已核实赠书在二月铁拳门，和师父夺魄、云裳留唐门的准备冲突，其他线不能默认顺路取得 |
| 完竟剑 | 按本书归入**小竹后期线**。先在图纸讨论选 **「销毁图纸」**，再选 **「为我造一柄剑吧」**；之后还有间章会面、去锻冶场交剑。其他线不要仅凭小竹好感高，就预设能收到最终交剑 |

**如果本周目走云裳线，可以先记这一组：切鱼刀、传承小剑，纸甲／猛火图纸二选一，再加牛皮制服；金钱剑看道德与骰点，万灵油看唐守鸿，沥泉枪头看叶云舟同行与好感，睡丹药方留到第三年八月委托、归来后领取。** 前期用菁英小剑，青城后比较牛皮制服与护心镜，后期再决定换传承小剑或沥泉小剑。其他路线按上面对应人物行规划，不预设也能取得青城物品。

**纸甲与猛火油柜图纸在上述事件中是不同骰点结果，一次不会同时拿到两张。** 该事件至少 66 的另一支给书；选高点数并不一定拿到你想要的图纸。

这里的睡丹、万灵油等是可炼制的养成道具。云裳救治仍要走完[她的完整路线](./活侠传关键节点选择攻略.md#cloud)里的剧情、问诊与《九转残篇》条件；炼出一份普通丹药不会补齐这些经历。

<a id="recipes--6-取得之后下一步查什么"></a>

## 6. 取得之后，下一步查什么

- [锻造与毒药](./活侠传关键节点选择攻略.md#crafting)：开发前置、门派规模、0→满级成本、决斗与战役效果。
